# Contributing to AgentBridge

Bug reports, reproducible test cases, documentation corrections, and design discussion are welcome through GitHub issues.

Before sending a code or documentation pull request, note that AgentBridge v0.5.0 and later uses a noncommercial public license and the maintainer intends to retain the ability to license the project commercially. A pull request does not automatically transfer your copyright or provide a separate relicensing grant.

External contributions will not be incorporated into a release until the contributor and HeadStone1 have agreed in writing to any contributor terms needed for distribution and commercial relicensing. Mark material that you do not intend as a contribution clearly in writing.

Never submit credentials, private discussion databases, customer data, or third-party code that you do not have permission to contribute.

For local validation, use Node.js 22.13 or newer and run:

```bash
npm ci
npm test
npm run release:npm
```

This file is contribution policy, not legal advice. The repository license remains controlling.
